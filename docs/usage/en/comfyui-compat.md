# ComfyUI compatibility

Khala supports the documented text-to-image nodes: checkpoint, CLIP, latent,
KSampler, VAE decode, SaveImage, PreviewImage, LoadImage and EmptyImage.
Unsupported nodes or workflows fail validation. Point a compatible frontend at
the Khala origin; `/` serves the pinned ComfyUI frontend when installed.
Full ComfyUI node and extension behavior is not implemented.
