# Getting started

Build the UI with `tools/build-ui.sh`. Start Khala with `art work`; the default
`engine = fake` needs no model or GPU. Open `/khala/` for the Khala UI and `/`
for the ComfyUI-compatible node editor.

Run the protocol suite with
`KHALA_SRC=/home/alexon/Project/khala KHALA_RUN_DIR=/tmp/khala-run7 sh tests/run-protocol.sh`.
